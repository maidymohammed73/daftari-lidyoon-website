# دفتري لديون — الموقع الرسمي
### Daftari Lidyoon — Official Website

موقع تعريفي (Landing Page) لتطبيق **دفتري لديون**، تطبيق عربي لإدارة الديون وحسابات العملاء.
مبني بـ **React + TypeScript + Vite + Tailwind CSS + Lucide Icons**، ويدعم العربية (RTL) والإنجليزية (LTR)، والوضعين الليلي والنهاري.

---

## 🚀 التشغيل

يحتاج [Node.js](https://nodejs.org) الإصدار 18 أو أحدث.

```bash
npm install        # تثبيت المكتبات (مرة واحدة فقط)
npm run dev        # تشغيل الموقع للتطوير → http://localhost:5173
npm run build      # بناء النسخة النهائية في مجلد dist/
npm run preview    # معاينة النسخة النهائية
```

> إذا ظهرت صفحة فاضية بعد تعديل الإعدادات: أوقف السيرفر (`Ctrl + C`) وشغّله من جديد بـ `npm run dev`.

## 🌐 الرفع على الإنترنت (مجاناً)

**الطريقة الأسهل: Netlify Drop (بدون حساب برمجي)**
1. شغّل `npm run build` (أو استخدم ملف `daftari-lidyoon-dist.zip` الجاهز وفك ضغطه).
2. افتح https://app.netlify.com/drop
3. اسحب مجلد `dist` وأفلته في الصفحة، فيصير للموقع رابط مباشر.

**أو Vercel / Netlify عبر GitHub:** ارفع المشروع على GitHub واربطه. الإعدادات جاهزة في `vercel.json` و`netlify.toml`.

بعد الرفع: عدّل رابط صورة المشاركة في `index.html` (`og:image`) ليصير رابطاً كاملاً مثل `https://your-site.netlify.app/og-image.jpg`.

## ✏️ قبل النشر الرسمي: عدّل هذه البيانات

كل الإعدادات في ملف واحد: **`src/data/content.ts`** → كائن `siteConfig`:

| الإعداد | الوصف |
|---|---|
| `googlePlayUrl` / `appStoreUrl` | روابط المتاجر. إذا تركتها فارغة تظهر شارة "قريباً". |
| `contactWhatsapp` | رقم واتساب بصيغة دولية بدون + (مثل `970591234567`)، فيفتح نموذج التواصل واتساب مع الرسالة. |
| `contactEmail` | بديل لواتساب: يفتح برنامج البريد مع الرسالة. |
| `social[].href` | روابط فيسبوك وإنستغرام وواتساب وإكس. |

**بيانات التواصل المعروضة** (رقم، بريد، عنوان) موجودة في `footer.contact` داخل `src/data/content.ts`.

**⚠️ للمراجعة:** نصوص قسم **الأمان والخصوصية** وصفحتي **سياسة الخصوصية** و**الشروط والأحكام** صيغ نموذجية. تأكد أنها تطابق ما يفعله التطبيق فعلاً (قفل التطبيق، النسخ الاحتياطي...)، وراجعها قانونياً قبل النشر. موجودة في `src/data/extras.ts`.

## 🤖 المساعد الذكي

الزائر بيكتب سؤاله بالعربي أو الإنجليزي، والمساعد بيرد عليه بنفس اللغة. في زر عائم "اسأل المساعد" بيوديك للمحادثة من أي مكان بالصفحة.

**وضعين** (الإعداد `assistantMode` في `src/data/content.ts`):

| الوضع | كيف بيشتغل | التكلفة |
|---|---|---|
| `'local'` (الافتراضي) | محرك مدمج في `src/lib/assistantBrain.ts` بيفهم الأسئلة عن التطبيق: المميزات، الديون، الدفعات، العملاء، التقارير، الأمان، السعر، التحميل، التواصل. بيتعامل مع اختلاف الكتابة (أ/إ/ا، ة/ه). | مجاني، بدون سيرفر |
| `'ai'` | ذكاء اصطناعي حقيقي (Claude) عبر دالة Netlify في `netlify/functions/assistant.mts`. إذا صار أي خطأ، بيرجع تلقائياً للوضع المدمج. | حسب استهلاك Anthropic API |

**تفعيل وضع الذكاء الاصطناعي:**
1. اعمل مفتاح API من https://console.anthropic.com
2. ارفع المشروع على Netlify **عن طريق GitHub أو Netlify CLI**. طريقة السحب والإفلات (Drop) ما بتشغّل الدوال.
3. في Netlify: Site configuration ← Environment variables، أضف `ANTHROPIC_API_KEY`.
4. غيّر `assistantMode` إلى `'ai'` وأعد الرفع.

المفتاح بيضل على السيرفر وما بيوصل للمتصفح أبداً. الدالة بتستخدم نموذج `claude-opus-5-5` بمجهود منخفض (`effort: 'low'`) للردود القصيرة، وبتحدّد طول الرسائل وعددها.

**لإضافة سؤال جديد للوضع المدمج:** أضف عنصر لمصفوفة `intents` في `assistantBrain.ts`، فيه كلمات مفتاحية وجواب بالعربي والإنجليزي.

## 🌍 اللغة والوضع

- زر **EN / ع** يبدّل اللغة والاتجاه (RTL/LTR) وعنوان الصفحة ووصفها.
- زر **🌙 / ☀️** يبدّل الوضع. أول زيارة تتبع إعداد جهاز الزائر.
- يُحفظ الاختيار في المتصفح ويُطبَّق قبل ظهور الصفحة، فلا يحدث وميض.
- روابط مباشرة: `/?lang=en` أو `/?theme=dark` أو `/?lang=en&theme=dark`.

## ♿ إمكانية الوصول والأداء

- HTML دلالي، عناوين مرتبة، ونصوص بديلة للصور.
- أزرار وقوائم بخصائص `aria`، وتنقّل كامل بلوحة المفاتيح، ورابط "تخطَّ إلى المحتوى".
- يحترم تفضيل "تقليل الحركة" (prefers-reduced-motion).
- الحجم النهائي تقريباً 76KB من JavaScript و8KB من CSS بعد الضغط.
